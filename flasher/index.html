Set up over USB

No firmware has been published yet. Build from source as described in the software guide.

Before you start
  • Connect the board over USB with a data cable. Some boards need BOOT held while plugging in.
  • Boards need at least 4 MB of flash.
  • A first install erases the board, including saved settings.
After installing
  1. Close the installer's dialog, which holds the port until then.
  2. Open Set up over USB and connect to the same board to configure your home network, the variant and the name.

Without Web Serial, join the Wi-Fi network Spot-Micro with password spot-leika, open http://192.168.4.1 and configure your home network under Wi-Fi.
